# LiveComplexity

Real-time algorithm complexity analysis for C++ — directly inside VS Code.

## Status

🚧 Under active development — not yet published to the VS Code Marketplace.

## Features (Planned)

- Detect loops and nested loops in C++ code
- Estimate time complexity (O(1), O(log n), O(n), O(n²), O(n³))
- Display complexity annotations inline in the editor
- Show detailed explanations on hover

## Development

```bash
pnpm install
pnpm run build
# Press F5 in VS Code to launch the Extension Development Host
```
