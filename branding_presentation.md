## Brand Style

* **Typography**: Clean, geometric sans-serif (Inter/Roboto) for marketing copy. Monospaced (JetBrains Mono) exclusively for `O(n)` complexities and AST node labels.
* **Palette**: 
  * **Background**: VS Code Slate (`#1E1E1E` to `#252526`)
  * **Primary Accent**: Algorithmic Cyan (`#00E5FF`) representing the structural AST parsing.
  * **Secondary Accent**: Pure White (`#FFFFFF`) for the definitive mathematical `O`.
* **Geometry**: Uniform stroke widths. Sharp 90° or 45° angles for tree edges. Absolute visual balance. No glow, no drop shadows, no neon gradients.

## Demo GIF Storyboard

A 20-second, 60fps sequence focused purely on typing reactivity.

* **0:00–0:05**: User types a clean `for` loop. The moment typing pauses, `O(n)` fades in inline.
* **0:05–0:10**: User nests another loop. The outer function annotation updates instantaneously to `O(n^2)`.
* **0:10–0:15**: User hovers over the signature. The deterministic math breakdown appears.
* **0:15–0:20**: User alters the loop bound to an external `M_INDIR` function. The engine instantly and safely classifies it as `Unknown`.
